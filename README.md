# Cat vs Dog Image Classification using Support Vector Machine (SVM)

This project was completed as part of my Machine Learning Internship.

## Objective
Develop an image classification model using a Support Vector Machine (SVM) to classify images as either cats or dogs.

## Dataset
Microsoft Cats vs Dogs Dataset

**Dataset Link:**
https://www.kaggle.com/datasets/shaunthesheep/microsoft-catsvsdogs-dataset

## Technologies Used
- Python
- NumPy
- Pandas
- OpenCV
- Matplotlib
- Scikit-learn
- Google Colab

## Workflow
- Import and preprocess image dataset
- Convert images to grayscale
- Resize images to 64 × 64 pixels
- Normalize pixel values
- Split dataset into training and testing sets
- Train the Support Vector Machine (SVM) model
- Evaluate the model using accuracy and classification metrics

## Results
- Successfully classified cat and dog images using a Linear SVM.
- Achieved approximately **55% test accuracy** on the selected dataset.
